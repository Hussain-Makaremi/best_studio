## Rules (do / don't)
**Do**
- Display type 103px+ for hero/section openers
- Display lh 0.73–0.75; letter-spacing 0.06em (non-negotiable)
- #e10600 only for actions, toggles, display type
- Pair filled Primary + Ghost CTA on the same row
- 15px radius for nav, CTAs, filters
- Irregular masks for food photos in hero zones; rectangles only in product cards
- Solid #000000 nav across all sections

**Don't**
- No shadows, glows, gradients
- No new chromatic colors (six-color discipline)
- No sans-meat below 10px or for long-form paragraphs
- Never body/secondary text in #e10600
- No rectangular food photos in hero zones
- Never soften display line-height below 0.80 _(as returned; conflicts with the 0.73–0.75 "do" — likely means never loosen above ~0.80)_
- Never a light/white page background

**Use cases:** plant-based consumer food, punk/attitude-forward positioning, product-led commerce, dark-mode-first high-contrast interfaces.

## Steal this
- A strict six-color palette where the accent doubles as display-headline color.
- Positive tracking (0.06em) on ultra-tight line-height (0.73) display — dense but legible poster blocks.
- Organic masks for hero food photos, rectangles for product cards — one rule separating "brand" from "shop".
- Bracketed eyebrow glyphs ("◂ … ▸") as cheap brand texture.
