# Onboarding Design Prompts

The first screen should establish visual rhythm before explaining features. References show warm welcomes, framed product previews, and playful brand moments.

## Prompt: Core task brief

The style document supplies the visual rules. Fill in the product facts before assigning to an agent.

```
Design first-run setup for [product] so [new user] can complete [first valuable action].
```

Accompanying rules (as given on the page): request only necessary inputs, show progress and validation, clarify back/skip policies, and explain what happens after completion.
